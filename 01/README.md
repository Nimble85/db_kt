# Практична робота 1

**Тема:** робота зі СКБД SQLite. Створення БД і таблиці. Імпорт-експорт, резервне копіювання та відновлення.

**Мета:** навчитись працювати з СКБД SQLite, створювати БД, робити імпорт-експорт БД, резервне копіювання та відновлення.

Консольний клієнт `sqlite3` (SQLite 3.51.0).

## Вимоги до індивідуального завдання (з методички)

> У окремій БД створити 2 таблиці із вказаними обмеженнями цілісності первинного ключа, обрав для створення БД довільну предметну область. Заповнити таблиці довільними даними (в кожній таблиці не менше 10 записів). Навчитись видаляти записи, робити експорт таблиці до зовнішнього файлу, робити резервне копіювання тощо.

## Що виконано

**Основне завдання** — `sql/01_main_task.sql`, БД `myFirstDB.db`:
- створення таблиці `students(id, name, age)` і наповнення даними;
- перегляд даних і схеми (`.mode column`, `.headers on`, `.schema`, `sqlite_master`);
- резервна копія БД (`.dump` у `myDump.sql`);
- експорт таблиці в CSV (`stud.csv`);
- видалення даних і імпорт із CSV (`.import --csv --skip 1`);
- відновлення БД із дампу (команда оболонки в кінці скрипта).

**Індивідуальне завдання** — `sql/02_individual_task.sql`, БД `library.db` (бібліотека):
- дві пов'язані таблиці `authors` і `books` (PK AUTOINCREMENT, FOREIGN KEY);
- 10 авторів і 12 книг, видалення записів;
- експорт у CSV, дамп і `.backup`, очищення та імпорт із CSV.

## Структура

| Шлях | Призначення |
|------|-------------|
| `report/` | Звіт: `Звіт_ПР1.docx`, `Звіт_ПР1.pdf` |
| `sql/` | Скрипти основного та індивідуального завдань |
| `logs/` | Транскрипти реальних сеансів `sqlite3` (`main_figNN`, `ind_indNN`) |
| `screenshots/` | Знімки консолі, згенеровані з логів, — рисунки звіту |
| `scripts/` | Драйвер сеансів, рендер скріншотів, складання звіту (див. нижче) |
| `db/` | CSV-експорти та SQL-дампи; бінарні `.db` не зберігаються, їх відтворюють скрипти з `sql/` |

## Запуск

```sh
mkdir work && cd work
sqlite3 myFirstDB.db < ../sql/01_main_task.sql
sqlite3 library.db   < ../sql/02_individual_task.sql
# відновлення з дампу
rm myFirstDB.db && sqlite3 myFirstDB.db < myDump.sql
```

## Скрипти в `scripts/`

Вони складені для робочого дерева `HT/01/` (`work/`, `src/ouput/`) і в цьому репозиторії наведені як документація того, як було отримано логи, скріншоти та звіт. Для перескладання звіту їх треба запускати в тому дереві.
