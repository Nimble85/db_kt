# Практична робота 3

**Тема:** робота зі СКБД SQLite. Виконання запитів на вибірку даних.

Консольний клієнт `sqlite3` (SQLite 3.51.0).

## Що виконано

**Основне завдання** — `sql/01_main_task.sql`: запити `select` до тестової БД «Страви» (таблиці `episodes`, `foods`, `food_types`, `foods_episodes`): вибірка стовпців, `distinct`, `where`, `like`, `order by`, `limit`, агрегатні функції, `group by`, `having`, з'єднання таблиць.

**Індивідуальне завдання** — `sql/02_individual_task.sql`: 7 запитів до тієї самої БД, виконаних в окремій копії.

Тестову БД відновлюють із дампу `sql/foods.sql` (отриманого з наданого `foods.db`; порожню таблицю `contacts` із дампу виключено).

## Структура

| Шлях | Призначення |
|------|-------------|
| `report/` | Звіт: `Звіт_ПР3.docx`, `Звіт_ПР3.pdf` |
| `sql/` | `foods.sql` (дамп БД), скрипти основного та індивідуального завдань |
| `logs/` | Транскрипти реальних сеансів `sqlite3` (`main_figNN`, `ind_indNN`) |
| `screenshots/` | Знімки консолі, згенеровані з логів, — рисунки звіту |
| `scripts/` | Драйвер сеансів, рендер скріншотів, складання звіту (див. нижче) |

Бінарні `.db` не зберігаються: їх відтворюють скрипти з `sql/`.

## Запуск

```sh
mkdir work && cd work
sqlite3 food.db     < ../sql/foods.sql
sqlite3 food.db     < ../sql/01_main_task.sql
sqlite3 food_ind.db < ../sql/foods.sql
sqlite3 food_ind.db < ../sql/02_individual_task.sql
```

## Примітки до результатів

- У `episodes` є два епізоди без номера сезону (NULL), тому `count(*)` дає 181, а різних сезонів — 9.
- Рис. 29: при рівній кількості згадувань порядок рядків не визначений, тому п'ятий рядок рейтингу може відрізнятися від методички.
- Довгі результати на знімках скорочено рядком `[... вивід скорочено ...]`.

## Скрипти в `scripts/`

Вони складені для робочого дерева `HT/03/` (`work/`, `src/ouput/`) і в цьому репозиторії наведені як документація того, як було отримано логи, скріншоти та звіт. Для перескладання звіту їх треба запускати в тому дереві.
